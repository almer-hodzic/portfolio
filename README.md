# Almer Hodžić — Portfolio

Developer portfolio showcasing HoopsLab, MovieShop, and software engineering work.

## Stack

React, TypeScript, Vite, React Router, Tailwind CSS, and Framer Motion. Static SPA with no required environment variables.

## Development

```sh
npm ci
npm run dev
```

## Build and checks

```sh
npm run build
npm test
npm run preview -- --host 127.0.0.1 --port 4173
```

Use `npm.cmd` in Windows PowerShell. Production output is `dist/`; `vercel.json` provides SPA fallback for direct project-route visits.

## Selected work

- **[HoopsLab](https://github.com/almer-hodzic/hoops-lab)** — historical NBA analytics, player comparison, roster construction, shot analysis, and a simulation API.
- **[MovieShop](https://github.com/almer-hodzic/MovieShop)** — Angular and .NET movie catalog, administration, persistent carts, and PayPal Sandbox checkout.

The homepage includes a real portrait and decorative paper-boat variants selected with `?boat=minimal`, `?boat=merry`, or `?boat=journey` (default Merry). Motion respects reduced-motion preferences.
